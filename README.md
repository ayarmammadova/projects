# AI & Data Science Projects

This repository contains selected university projects in Artificial Intelligence and Data Science.

## Projects

### Traffic Prediction (LSTM vs GRU)
Time-series forecasting of traffic speed using recurrent neural networks.
Focus: model comparison and evaluation.

### Super-Resolution (EDSR, SRGAN, ESRGAN)
Deep learning image super-resolution pipeline with dataset preparation and model comparison.
Focus: PSNR/SSIM evaluation and perceptual quality.

### Restaurant System Architecture
Full-stack web application architecture with frontend-backend separation and REST API design.
Focus: software architecture and UI implementation.
